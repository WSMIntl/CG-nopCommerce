# ChemSynt 301 standalone parity gap analysis

Audit date: 2026-08-12

Reference: https://www.velp.com/en-ww/chemsynt-301-chemical-reaction-station.aspx

## Scope and audit method

This audit compares the current local `index.html`, `css/styles.css`, `js/app.js`, asset manifest, README, image directory, and packaged ZIP with the live reference page and its linked ChemSynt 301 configuration advisor. The live page was inspected at desktop and phone widths, its controls were exercised, and its public product/form endpoints were queried to capture the exact state returned for both models.

The agreed scope excludes the VELP-wide header, menus, account/search tools, cookie banner, analytics, shopping cart, and global footer. Those items are therefore not implementation gaps. The reference reports `isSale: false` for this market, so its add-to-cart path is unreachable and is also outside the required Chemglass quote-only adaptation.

The standalone version must not make runtime calls to VELP. Live endpoint data needed by the in-scope interactions will be embedded locally. VELP contact and lead-submission actions must become local Chemglass Technical Service email handoffs.

## Implementation resolution

All required corrections in the inventory above were implemented in the final source tree. Existing correct product copy, technical values, gallery assets, and Chemglass contact routing were retained; the work concentrated on missing stateful behavior, exact model/accessory data, the dedicated configuration flow, responsive parity, and offline delivery integrity.

Two source behaviors were deliberately adapted for a standalone Chemglass package:

- VELP's authenticated brochure endpoint is represented by an equivalent local lock/request dialog that routes the request to Chemglass Technical Service.
- VELP's server-side, reCAPTCHA-protected lead APIs are represented by fully validated local forms that generate complete prefilled Chemglass Technical Service emails and expose copyable fallbacks.

Final source-tree verification completed successfully:

- 43/43 automated browser interaction and responsive checks passed with no runtime exceptions.
- Both endpoint-derived model inventories passed exact count checks: 3/6/40 groups for SA110A0710 and 45 optional accessories for F110A0710.
- All 58 distinct runtime image references resolve to non-network local files, and the manifest matches the image directory 58/58.
- No HTTP or HTTPS dependency remains in either runtime HTML/CSS/JavaScript entry point.
